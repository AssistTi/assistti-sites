# AssistTI Sites

Versão inicial do editor visual multi-site com GrapesJS.

## Recursos disponíveis
Cadastro demonstrativo de clientes e sites, edição por arrastar e soltar, edição de estilos, dispositivos, desfazer/refazer, prévia, importação e exportação HTML e rascunhos no navegador.

## Limitações
Os dados são salvos apenas em localStorage. **Não há autenticação real, autorização por cliente, sincronização ou publicação automática.** Não disponibilize o painel a clientes como se fosse um sistema seguro. O editor carrega GrapesJS por CDN.

## Próximas etapas
Autenticação e banco de dados, controle de permissões por site, armazenamento de mídia e serviço seguro de publicação no GitHub Pages.
